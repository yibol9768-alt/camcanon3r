\section{Method}
\label{sec:method}

\subsection{Overview}
CamCanon3R separates a coordinate intervention from the model response it is
intended to preserve.  Given a logged image affine, we first compose all user
and model pixel maps, then compare predictions on their common source support.
For repair, we analytically return each input to a canonical camera canvas
before reconstruction.  This design exposes residual model non-equivariance
without pretending that inverse warping can restore content removed by a crop.
Figure~\ref{fig:method-overview} summarizes the audit and separately gated
repair paths.

\subsection{Preprocessing-equivariance contract}
Let source image $I_i$ have camera matrix
$P_i=K_i[R_i\mid t_i]$.  A controlled nonsingular image-coordinate affine
$A_i\in\R^{3\times3}$ produces $I'_i$ and changes the camera to
\begin{equation}
  P'_i=A_iK_i[R_i\mid t_i].
\end{equation}
If the model applies an internal pixel map $B_i$, the complete source-to-model
map is $C_i=B_iA_i$.  Nonsingularity concerns coordinates, not image content:
a crop restricts the sampled domain and is therefore not information
invertible.  We store $A_i$, $B_i$, $C_i$, and the valid source support rather
than infer them after prediction.

\subsection{Common-domain comparison}
The contract is only measurable after both pixel coordinates and 3D gauge are
removed.  Predicted pixel-aligned quantities are mapped through $C_i^{-1}$ and
compared only on common visible support.  Relative rotations and
translation directions are evaluated over all view pairs, eliminating
arbitrary world frames and translation scale.  Depth is compared after one
declared scene-level median scale alignment.  An identity-repeat run measures
the numerical noise floor.

For raw ETH3D point maps, we backproject the original-image z-depth through its
thin-prism fisheye calibration and retain predicted points only where the
inverse pixel map lands on finite scan-supported depth.  We fit one
orientation-preserving Sim(3) using camera poses only: the chordal mean of
paired rotations fixes global rotation, then camera centers determine positive
scale and translation. Ground-truth surface points do not optimize the
alignment.  We sample at most
100k finite supported pixels per view, then apply a \SI{1}{cm} voxel grid and
deterministic 100k-point pooled cap.  Untruncated bidirectional nearest-neighbor
distances give accuracy and completeness.  This is a raw-depth-derived
point-map evaluation, not the official ETH3D MVS leaderboard protocol.

\subsection{Analytic canonical-camera repair}
A crop-resize changes coordinates and removes content, but only the former is
analytically reversible.  Let $\Omega_i$ and $\Omega'_i$ denote the source and
prepared canvases.  We construct a repaired image on $\Omega_i$ as
\begin{equation}
  \widehat I_i(\mathbf{x})=
  \begin{cases}
    I'_i(A_i\mathbf{x}), & A_i\mathbf{x}\in\Omega'_i,\\
    \boldsymbol\mu, & \text{otherwise},
  \end{cases}
  \label{eq:canonical-repair}
\end{equation}
where $\boldsymbol\mu$ is a fixed neutral-gray fill.  The binary validity mask
$M_i(\mathbf{x})=\mathbf{1}[A_i\mathbf{x}\in\Omega'_i]$ records the visible
support and is reported with every result.  Because $\widehat I_i$ again uses
the source canvas, its protocol affine is identity and its camera intrinsics
are $K_i$, not $A_iK_i$.  The repair therefore removes the induced focal and
principal-point change while preserving the unavoidable information loss.
Processing identity through the same path provides the clean-cost control.

\subsection{Disagreement and repair}
The analytic repair is evaluated before any learned or ensemble component.
Cross-transform disagreement is the median pairwise rotation difference among
reconstructions of frozen equivalent preprocessings.  We promote it as a
failure score only after testing the unchanged score and $>\!2$-degree GT
failure threshold on held-out DTU.  This is a deterministic consistency signal,
not a posterior uncertainty distribution.

Larger scores always denote greater uncertainty.  We use average-rank AUROC
for ties and construct risk--coverage curves by adding complete equal-score
blocks, avoiding dependence on arbitrary row order.  Oracle ranking by GT
error defines the minimum reference AURC; we report raw and excess AURC and
resample complete scenes as clusters.  Consensus selection is separately
eligible only if it beats Eq.~\eqref{eq:canonical-repair} for both models at a
matched compute budget; its failure cannot invalidate the analytic repair.
